# The Zoo Game

First browser-based prototype for a zoo-building bidding game inspired by the
mechanics of Time Travel Tours.

## Run locally

Open `/Users/timcollins/Documents/New project 2/index.html` directly in a web
browser.

If you prefer a tiny local web server, from this folder you can also run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Prototype features

- Splash screen and office/dashboard flow
- 1 human player vs 2 AI zoo owners
- First-to-15,000 visitors victory goal
- 8 random card reveals each round with a changing zoo/people mix
- Zoo cards for animals, attractions, and exhibit sections
- Animal inventory tracking inside your zoo collection
- Preference-based people cards that can wait for the right zoo match
- Per-turn upkeep costs and revenue-roll scoring
- Natural visitor growth each round
- Final leaderboard
