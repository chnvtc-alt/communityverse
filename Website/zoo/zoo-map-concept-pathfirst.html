Why This Feels Closer

This version stops asking the player to read the park as a set of districts first. Instead, it asks them to read it as a zoo: paths, loops, landmarks, named areas, and routes around the lake. The bigger categories still matter in the game logic, but the map itself feels like a place rather than a diagram.

  • Themed areas are implied by clustering, not tinted regions.
  • Restaurants and shops can live naturally inside the same clusters as the attractions they support.
  • This format should scale better as more exhibit spots get added over time.
If this is closer to the feeling you want, I would switch the future map work from “district map with overlays” to “visitor map with hidden theme logic underneath.”
