What Changed In V2

This pass is less about adding more detail and more about changing the visual language. The district boundaries are now carried by terrain and path structure first, while the labels are visibly anchored with solid leader lines.

  • The map should feel less like tinted blobs and more like real lands inside a shared park.
  • The leader lines are intentionally stronger now so they actually do their job.
  • The next step after this would be adding tiny illustrated exhibit icons or silhouettes onto the numbered pads.
If this finally feels close enough, this is the version I would use as the visual target for the eventual in-game map rebuild.
