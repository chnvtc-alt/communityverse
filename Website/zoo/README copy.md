# Character Image Library

Store character reference images here for future use in game UI, cards, rosters, and marketing.

## Staff Images

Place staff images in:

- `assets/characters/staff/`

Recommended format:

- `PNG` for now
- RGB color
- clear filename based on character slug, for example:
  - `smiley-boy.png`
  - `johnny-pepper.png`
  - `renee-potato-salad-long.png`

These images are not required by the game UI yet. They are being stored here so the project has a consistent art library when we are ready to display staff portraits later.
