What This Version Adds

This is the same general plan as the organic concept, but with a much more illustrated-map mood. The land looks painted instead of blocked in, and the district edges are defined more by natural terrain, path loops, water, and tree belts instead of flat color shapes.

  • Districts feel more like lands inside a park and less like dashboard panels.
  • Leader lines keep labels readable without forcing text into the middle of busy areas.
  • The smaller numbered pads still solve the problem of fitting a lot of exhibits onto one shared zoo map.
  • This style would work well with little exhibit icons or silhouettes later, once actual placements start appearing in-game.
If you like this direction, the next real build could use this style as the visual base and keep the numbered placement-pad logic underneath so the map stays playable.
