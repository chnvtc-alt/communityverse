Customer field guide

Customer name: The name players will see after winning this customer.

Group name: The database category for organizing customers, like exclusive, historical, storybook, communityverse, or staff.

Rarity / difficulty: Common appears most often and is easiest to win. Uncommon is in the middle. Rare appears less often and needs a better score.

Regular value: Use ranges so customers still feel individual. Common $75-$125, Uncommon $125-$200, Rare $200-$350.

Occasional value: Use a smaller amount for partial wins. Common $20-$40, Uncommon $40-$70, Rare $70-$125.

Restaurant: Choose Shared for every restaurant, or choose one restaurant so the customer only appears there.

Sort order: Lower numbers show first in the control room. It does not need to be perfect.

Bio: Short player-facing description of the customer.

Question place: Where the customer is connected to, if you want the game to ask about it.

Question fact: A short fact the game can use for customer-related trivia.

Photo URL / path: You can leave this blank if you use Replace photo. The upload will fill it in when you save.

Replace photo: Upload a 512 x 512 JPG square customer picture.
